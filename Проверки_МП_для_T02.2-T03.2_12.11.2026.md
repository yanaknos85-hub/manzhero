# T02.2 / T03.2: вопросы команде МП

Редакция 13.11.2026.

Решение: в МП делается отдельный экран заказа по избранному маршруту по образцу WEB. WEB и МП описываются одним документом «T02.2 / T03.2». Правки для объединения — в файле «Правки_к_T02.2_объединение_с_T03.2_13.11.2026».

Отдельный экран МП описывается нашим документом, поэтому проверять форму заказа МП на стенде больше не нужно. Остаются вопросы команде МП: от ответов зависит, какие блоки МП переиспользует, а какие делаются заново.

По коду установлено: WEB всегда передаёт в заявке source = WEB, а сервис заявок принимает MOBILE_IOS и MOBILE_ANDROID от другого клиента. Значит, МП — отдельное приложение, которое вызывает тот же метод создания заявки. Кода МП в наших репозиториях нет.

## 2. Что ещё нужно для приёмки МП

- Тестовые сборки iOS и Android и учётная запись сотрудника с правом заказа такси и трансфера.
- Способ увидеть данные заявки, созданной в МП: открыть её в WEB в «Мои заявки» и посмотреть ответ GET /api/requests/{id}. Персональные данные из ответа в материалы не копировать, фиксировать только наличие полей и формат.
