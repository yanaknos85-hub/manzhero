ПРИНЯТЫЕ РЕШЕНИЯ (отразить в документе)
Р1. Количество пассажиров задаётся одним штатным счётчиком. Блок гостя показывает столько полей ФИО, сколько пассажиров указано.
Р2. Автобусные классы TAXI (VIP_BUS, SMALL_BUS, MIDDLE_BUS, LARGE_BUS): количество — по штатным правилам вместимости класса, данные гостя — один контакт (ФИО и телефон), как у трансфера.
Р3. GROUP_TRANSFER, включая TRANSFER_CAR_CHOICE: данные гостя вводятся в штатном блоке «Дополнительное контактное лицо»; отдельного блока гостя у трансфера нет.
Р4. Состав сетевых реквизитов ИМ в заявке определяет T04.1. В T02.2 фиксируются только favoriteRouteId и favoriteRouteVersion.

1. 5.3, подраздел «Данные гостя» — заменить целиком
Новый текст:
«Блок «Данные гостя» необязателен и дополняет штатный блок «Кто пассажир?». Пассажир заявки определяется штатным режимом. Количество пассажиров задаётся штатным счётчиком; passengerCount — общее число едущих пассажиров. Для каждого указанного гостя ФИО обязательно. Телефон гостя-контакта необязателен и вводится в формате +7.

Легковые классы TAXI. Штатный счётчик «Укажите количество пассажиров» (от 1 до 4) показывается на экране заказа по ИМ всегда, независимо от «Совместной поездки». Блок гостя показывает столько полей ФИО, сколько пассажиров указано. ФИО каждого гостя вводится одной строкой; телефон — только для первого гостя.

Автобусные классы TAXI (VIP_BUS, SMALL_BUS, MIDDLE_BUS, LARGE_BUS). Количество пассажиров — по штатным правилам вместимости класса. Данные гостя — один контакт: ФИО и телефон.

GROUP_TRANSFER, включая TRANSFER_CAR_CHOICE. Количество пассажиров — штатное поле. Данные гостя вводятся в штатном блоке «Дополнительное контактное лицо» (ФИО и телефон); отдельного блока гостя нет.

В запросе создания заявки T02.3 передаёт ФИО гостя-контакта — первого гостя легкового TAXI, единственного контакта автобусного класса или GROUP_TRANSFER — в information.addContactFIO, телефон при наличии — в information.addContactPhone.

ФИО остальных гостей легкового TAXI передаются в commentForDriver строкой «Пассажиры: ФИО2; ФИО3; ФИО4» в порядке ввода и только для указанных гостей. При заполненном комментарии водителю строка с гостями идёт первой, после перевода строки передаётся комментарий пользователя. При пустом комментарии передаётся только строка с гостями. Без дополнительных гостей действует штатный комментарий водителю.

При пустом блоке поля контактного лица и строка с гостями не передаются. Комментарий водителю формируется по штатным правилам.

Ручной ввод действует до появления режима «Мой клиент». Затем ФИО выбирается из базы клиентов. Диспетчерская и приложение водителя отображают введённые сведения в штатных полях заявки.»
Почему: в v0.7 количество задавалось и в блоке гостя, и штатно; ограничение «от 1 до 4» распространялось на автобусные классы TAXI; у трансфера было два блока для одних и тех же полей контактного лица.
