**Тема:** FavoriteRoute (Избранные маршруты): доступы и тестовые данные на stage

Коллеги, добрый день!

Для проверки сервиса FavoriteRoute на стенде нам нужны доступы и данные с вашей стороны. Просим помочь по списку ниже.

**1. Развёртывание сервиса на stage**
Окружение для FavoriteRoute, база PostgreSQL, записи конфигурации в Config Server.

**2. Права и тестовые пользователи**
- Применить миграцию прав для публичных URL FavoriteRoute с ролями ROLE_EMPLOYEE_CORP_CLIENT, ROLE_ADMIN_CORP_CLIENT, ROLE_ENGINEER_CORP_CLIENT (миграцию подготовим мы).
- Тестовые пользователи с каждой из этих ролей в организации Манжерока.

**3. Сетевой доступ со stage FavoriteRoute**
corporate, tariff-main, geo, geo-zones.

**4. Тестовые тарифы организации Манжерока**
TAXI и GROUP_TRANSFER, договоры INCOME и TRANSITIONAL, дневной и ночной тарифы, TRANSFER_CAR_CHOICE с закреплённым автомобилем.

**5. Kafka**
Адрес брокера, права на чтение топика `service.request`, consumer group для FavoriteRoute и возможность отправить тестовую заявку.

**6. Сервисный субъект для реестров**
Сервисный субъект для реестров (T05.1/T05.2) и отдельное разрешение на внутренний URL чтения исторической версии маршрута.

**7. Логи и мониторинг**
Доступ к логам и мониторингу FavoriteRoute на stage.

**8. Значение настройки tariff-main**
Подтвердите, пожалуйста, значение `traffic.threshold` на stage: через API оно не отдаётся, а в коде задано значение по умолчанию 7.

Если по какому-то пункту нужен отдельный запрос в вашей системе заявок, подскажите, куда и в каком формате его направить.
