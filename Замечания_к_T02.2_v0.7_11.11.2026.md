# T02.2 «Автозаполнение заявки»: замечания к версии 0.7

Редакция 11.11.2026 · к документу `T02.2_Avtozapolnenie_zayavki_v0.7_20261111.docx`.

Правило для документа прежнее: только решения, ссылки только на документы проекта, без упоминаний стенда, кода и источников.

## 1. Итог проверки

Все правки из промта для v0.7 и три уточнения внесены: режимы штатного блока «Кто пассажир?», блок «Данные гостя» и его маппинг, исключение запрета на пересечение заявок, цель поездки, часовой пояс, смена версии, повторная availability при «Заказать», состояния «нет segments» и «нет расходного тарифа такси», связь с БТ, раздел 8, AC-T02.2-37…40. Схема последовательности отражает повторную проверку, данные гостя и возврат ошибок T02.3 на экран.

Паспорт документа убран намеренно — принято.

## 2. Решения по блоку гостя (приняты 11.11)

| № | Вопрос | Решение |
|---|---|---|
| Р1 | Количество пассажиров | Один штатный счётчик. Блок гостя показывает столько полей ФИО, сколько пассажиров указано. |
| Р2 | Автобусные классы TAXI | Как у трансфера: количество — по штатным правилам вместимости класса, данные гостя — один контакт (ФИО и телефон). |
| Р3 | GROUP_TRANSFER | Данные гостя вводятся в штатном блоке «Дополнительное контактное лицо»; отдельного блока гостя у трансфера нет. |

В AC-T02.2-37 условие: «указать количество 3 и ФИО трёх гостей». | Сейчас количество задаётся в двух местах (блок гостя и штатное поле), значения могут разойтись.
