# T02.2: правки по расходной стоимости

Редакция 05.11.2026 · дополнение к `Замечания_к_T02.2_v0.3_05.11.2026.md`. Разделы указаны по нумерации v0.3.

Решение: форма T02.2 не вычисляет и не передаёт `expected.outcomeCost`. Без этого поля заявка создаётся, сервис заявок записывает 0. Подставлять `fixedCost` нельзя: для заявок по ИМ правило «расход равен доходу» из обычного расчёта трансфера не применяется. Расходную стоимость для всех видов проставляет бэкенд в T04.2.

T01.1, T01.2, T01.4 эти правки не затрагивают: расходная стоимость в них не используется.

## Для T04.2

- Проставить `outcomeCost` для заявок по ИМ всех видов: такси, трансфер, `TRANSFER_CAR_CHOICE`.
- Правило обычного расчёта трансфера «расходная стоимость равна клиентской» к заявкам по ИМ не применять.
- Определить `outcomeTariffId` для такси.
