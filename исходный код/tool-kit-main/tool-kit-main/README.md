# Front Tool Kit

## Установка

```js
yarn add @sber-sbertransport/tool-kit --save-dev
```

## Апгрейд версии пакета

Версия должна строго следовать требованиям [semver](https://semver.org/lang/ru/)

- **Для фиксов**: `yarn version --patch`: v1.0.1 => v1.0.2
- **Для фич**: `yarn version --minor`: v1.0.2 => v1.1.0
- **Для серьезных или несовместивых изменений**: `yarn version --major`: v1.1.0 => v2.0.0
